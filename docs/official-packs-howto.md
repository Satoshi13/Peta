# 公式パックを、アプリの更新なしで配る（オーナー向け）

2026-10-17、第2弾対応。中身（絵・名前・レア度・無料か有料か・値段）は**オーナーの Mac の上で公式の鍵で署名**し、掲載期間と停止は管理ページで決めます。

```text
管理ページ「パック」  1. 作る → 2. Mac で署名する → 3. 並べる
オーナーの Mac       bash scripts/sign-pack.sh <draftId> prod
各 Mac の Peta       自動取得、または Settings → Check for new packs and news
```

- beta・Developer の公式ショップは、管理ページで作った署名済みパックだけです。Tokyo・Coffee・Houseplants・Pixel Dream・Cats・Night Market は並びません。通信しない offline 版には内蔵6パックが残ります。
- 初回の Welcome Pack は別のものです。従来どおり棚に入り、動きも変わりません。
- 有料パックは買うたびに同じ中身の1セットが棚に入ります。無料パックは1台の Mac のライブラリにつき1セットだけ受け取れます。同じ ID の次の版を出しても、もう一度は受け取れません。
- 期間終了・停止でショップから消えても、**棚にある分はいつでも開けられます**。

> dev では無料・有料とも、作成から署名、手動取得、開封、停止後の開封まで確認済みです。本番の k2 の準備・配布は別途必要です。今回、本番へのデプロイや鍵の変更は行っていません。[確認報告](official-packs-report.md)。

## 1. 最初に一度だけ: 公式の鍵 k2

本番のパックは k2 で署名します。k2 が入っていない版は検証できないため、並べません。先に対応版を配ります。

1. ネットワークを切った Mac で鍵を作ります（[official-key-howto.md](official-key-howto.md)）。
   ```sh
   cargo build --release --manifest-path src-tauri/Cargo.toml -p peta-pass
   src-tauri/target/release/peta-pass keygen --out /Volumes/Peta-private/official.key
   src-tauri/target/release/peta-pass pubkey /Volumes/Peta-private/official.key
   ```
   `/Volumes/Peta-private` は暗号化ディスクです。鍵はその外へコピーしません。最後のコマンドに出るのは公開鍵だけです。
2. 公開鍵を `src-tauri/crates/core/src/official_keys.rs` の `KEYS` の末尾に `("k2", Some("…"))` として追加します。k1 を消したり順序を変えたりしません。
3. その版のアプリを配ります。
4. 本番のパックを署名して並べます。

dev は公開済みのテスト鍵 k1 を使います。通常版・ベータ版は k1 を信用しません。本番では使いません。無料パックは第2弾に対応した版が必要です。非対応の古い版は、その無料パックを無視します。

## 2. 反映の準備

D1 に `0011_shop_packs.sql`（下書き・掲載・トークン）と `0012_shop_pack_free.sql`（無料フラグ）を当てます。`peta-api`・`peta-admin` を反映する手順は dev で先に確認します。

```sh
cd cloudflare/peta-api
npx wrangler d1 migrations apply peta-dev --remote --env dev
npx wrangler deploy --env dev
cd ../peta-admin
npx wrangler deploy --env dev
```

本番はオーナーが別途判断して行います。`peta-admin` の `PETA_ENV` が、画面に出す署名コマンドの行き先（dev / prod）を決めます。今回の dev 確認では 0012 だけを追加し、ローカル Worker から dev D1/R2 を使いました。

## 3. 作る（管理ページ「パック」）

1. 「新しいパックの ID」に英数字・`-`・`_` の40字以内（例 `autumn-walk`）を入れ、「下書きを開始」。ID は固定です。内容を変えるときは同じ ID の新しい版を作ります。
2. タイトル、作者（既定 Peta）、Market の説明、袋、色を設定します。袋はクラフト・マット・ホログラム・グラシン、色はマットとホログラムだけです。
3. 有料なら4〜40 Scraps。無料なら「無料（1台1セット、Welcome と同じ扱い）」をオンにします。無料は値段0として署名され、有料の交換・買い増しはできません。
4. アプリの **Collection → ステッカー → Share → Cut-out for a pack → Save…** で書き出した PNG をドラッグします。複数選択もできます。取り込みと保存が終わるまで、追加・保存・署名準備のボタンは待機します。
5. 各ステッカーの名前、レア度、重み（1〜100。空なら common / uncommon / rare が4 / 2 / 1）、順序を設定します。実際の袋と、素材のフチを付けた絵、抽選確率がプレビューに出ます。
6. 3〜12枚そろったら「署名の準備をする」。確認後は変更できません。直すなら複製して新しい下書きを作ります。
7. その場に出るコマンドをコピーします。暗号化ディスクを開き、Mac のターミナルに貼り付けます。

### アプリから絵を書き出す

Share シートには3種類あり、どれも Copy / Save… が使えます。

| 種類 | 用途 |
|---|---|
| Share card | 背景つき3:2の共有画像 |
| Sticker (transparent) | フチ・素材の見た目つき透過PNG。影なし |
| Cut-out for a pack | フチと影のない切り抜き。公式パック用。長辺1024px以下 |

ファイル名は `Peta <名前>.png`、切り抜きは `Peta <名前> cut-out.png`。日本語の名前も使えます。切り抜きの外は透明になり、元の写真全体は出力しません。完成画像しかない Gift や完成済みパックの絵は、安全に元の切り抜きを取り出せないため、この種類を選べません。その場合でも完成ステッカーの透過書き出しは使えます。

絵は透明背景のPNG、縁取り・影なし。長辺1024px以下、1枚1.5MB以下、合計12MB以下です。管理ページも大きな絵を縮小し、背景が不透明・空・縮小後も大きすぎる場合は日本語で理由を出します。絵柄は[design-principles.md](design-principles.md)も参照してください。

## 4. Mac で署名する

```sh
bash scripts/sign-pack.sh d-0123456789abcdef prod
```

1. Wrangler のログインを使い、D1 の下書きと R2 の絵を一時フォルダに取ってきます。管理ページを経由しません。
2. `peta-pass shop-pack --check` が、アプリと同じ上限と版番号を検査します。
3. **取ってきた絵のプレビューを1枚ずつ確認します**。名前・無料/有料・価格・確率・袋も確認します。サーバー上ですり替えられた内容を署名しないための確認です。おかしければ `n`。
4. `y` で署名します。鍵を読むのは `peta-pass` だけです。鍵の既定は `/Volumes/Peta-private/official.key`、`PETA_SIGNING_KEY` で変更できます。prod は k2、dev は k1。
5. 再検証した `.peta` を R2 に置き、「署名済み（未掲載）」にします。まだショップには出ません。一時フォルダは削除されます。

## 5. 並べる・取得する・止める

- 「署名済みパック」の「内容を見る」で、署名したファイルそのものの絵と文字を確認できます。
- 開始・終了（または「終了日なし」）を入力し、ショップに並べます。期間は後から変更できます。署名し直す必要はありません。同時に掲載中・予定にできるのは24パックまでです。
- アプリは起動・前面化時に6時間に1回まで自動取得します。すぐ確かめるには **Settings → Check for new packs and news**。パックの一覧・ファイルと、確率表・ニュース・ショップ設定をまとめて取得します。
- 結果は `2 new packs arrived.` / `Up to date.` / `Couldn't connect.`。beta は1分に1回で残り秒数を表示し、Developer は待ち時間なしです。変化があったときだけ関連画面を更新します。
- 無料パックは Market の `Get — Free` で1セット。受け取り後は `Received` になり、別の版でも再取得できません。棚では、準備済みの無料開封から先に進みます。
- 有料パックは Scraps でセット購入します。Developer の検証時は `Free (developer)` となり残高を減らしません。
- 「ショップから外す」は確認つき。次回の取得後に消えますが、棚の分は開けられます。再掲載には「新しい版を作る…」を使います。
- 下書きは「捨てる」で片付けます。こちらも確認つきです。

### Shop で目立たせる

「ショップ」の Featured / New and popular には、届いた公式パック（`shop:<packId>`）を指定できます。有料の価格調整は署名した値段の50〜200%。無料には値段を設定できません。オンライン版は内蔵6パックの指定を無視します。

新しい ID を指定した設定は、その ID を知らない古いアプリでは設定ごと無視されます。対応する版とパックが届いてから Featured にします。

## 6. 古いファイルを片付ける

「古いファイルを整理…」は、新しい版がある販売終了版と、捨てた・署名済みの下書きの絵を R2 から削除します（確認つき）。棚の絵は各 Mac に保存済みなので開けられます。現在の最新版を停止しただけでは、次の版がない限り古い署名ファイルの整理対象にはなりません。

## 7. うまくいかないとき

| 症状 | 確認するところ |
|---|---|
| `not ready to sign` | 管理ページで「署名の準備をする」を完了したか |
| `not newer than the signed vN` | 署名済みの版は再署名せず、新しい版を作る |
| `No key file at …` | 暗号化ディスクを開いたか、`PETA_SIGNING_KEY` が合っているか |
| 絵の取り込み中に操作できない | アップロードと自動保存が終わるまで待つ |
| 背景が透明ではない | Share card ではなく Cut-out for a pack を使う |
| 掲載しても届かない | 対応版・本番k2入りか、期間内か。手動取得ボタンで確認 |
| 無料をもう一度受け取れない | 同じライブラリでは同じパックIDを一度だけ受け取れる仕様 |
| 同時掲載の上限 | 掲載中・予定を24パック以内にする |
