# Studio と My shelf 修正報告

2026-10-12。版・景品の一覧、選択表示、表紙位置、装飾の保存後表示、完成済みパックの保管を修正しました。

## 画面

- Editions と Prizes を1つのスクロール領域に収め、Done は固定。長い名称は省略し、画像・枚数・割合を分けて表示します。景品も同じ ± ボタンに統一し、在庫・景品10個・全200スロットの上限を反映します。
- 受け取った本物は移動アイコンと「1」、在庫はストックアイコンと数で表示。説明はツールチップに残しています。
- レア度の文字凡例を削除。素材の枠・発光は選択後も変えず、チェックだけを追加します。包装・Accent・位置選択の緑の枠も廃止しました。
- Layout を Cover position に変更。Center / Corner / Top が包装ごとに異なる位置になります。表紙なしで位置を選ぶと、選択済みの自作デザインから表紙を追加します。自作デザインがない場合は選べず、理由を表示します。表紙の自由配置も維持します。
- Accent は銀のクリップ・紙テープ・封蝋。既存の素材を使い、クリップの大きさ・影・初期位置を調整しました。旧 Pin のデータは引き続き表示できます。新しい seal を含むファイルは更新後のアプリで扱います。
- Studio・棚・開封で同じ BagPic の表紙と装飾を使います。従来の kraft / matte / holo も保存された layout を表示します。包装の傾きも同じ名前・包装から決め、画面ごとのずれをなくしました。
- 表紙専用の取得コマンドを追加。抽選用の見本3枚に入らないデザインや、受け取り側ですでに引いたデザインでも、指定した表紙を表示します。

## My shelf

My shelf は完成済みパックを季節ごとに取り出すための保管場所です。受け取った開封用パックとは棚を分け、自作パックの詳細に Save file を追加しました。自分では開けられません。

Seal 時に署名済みファイルの全バイト列を内部アーカイブに保存します。再書き出し・File から My shelf への追加は packId だけで、この同じファイルを使います。再 press・版の増刷・景品や本物の追加消費はありません。すでに棚にある場合も補充しません。

保存には復旧ジャーナルと毎回一意の DB receipt を使い、保存・SQL 失敗で既存ファイルを戻します。署名・作者の鍵・パックID・digest を確認し、棚の記録とも照合します。以前の V13 自作パックは、既存のヘッダと画像から元のファイルと完全一致する場合に限ってアーカイブを復元します。

追補（2026-10-12）：このMacの Market への出品・取り下げ・同じ完成品の再出品を追加しました。公開状態は DB V14 に保存します。詳細は [local-market-report.md](local-market-report.md) に記載しています。共有 Market と経済の接続は別工程です。
