# Codex に送るメッセージ(見本ステッカーのリスタイル)

そのまま貼り付けて送る。

---

Peta の見本ステッカーを、質感のあるイラスト調に作り直してください。Stage 2 の見本12枚は「4色以内のフラットなベクター調」でしたが、オーナーが好きな絵柄は参考画像のような**ペイント調のイラスト**でした。紙・封筒など他の素材と質感を揃えるための変更です。

**最初に読むもの(この順)**
1. `docs/art-restyle-spec.md` — 今回の仕様書です。絵柄(STYLE-sample)、12題材のプロンプト、直す範囲、手順、検査ルール、チェックリストがすべて書いてあります。
2. `docs/art-reference/style-target-stickers.jpg` — 目指す絵の参考画像。**上段のPCに貼られたステッカーの質感**が目標です。下段(Tokyo Pack の中身の手描きスケッチ)は今回の対象外です。
3. `docs/art-stage2-audit.md` — 先日の監査。今回あわせて直す2点(紙テクスチャ、ヒーローの構図)が書いてあります。
4. `docs/codex-art-prompt.md` — 従来の指示書。§8.7(見本)の絵柄指定は、仕様書が優先します(「4色まで」「フラット」は無効)。

**やること**
- 見本12枚を作り直す(ファイル名・被写体・寸法・8pxの透明余白は従来どおり。白フチ・接地影・背景は付けない)。
- あわせて直す: `onboarding/hero.png`(5枚・重なり・傾き・中央の余白)、`book/cover-kraft.png` の花ステッカー、`back/paper-cream.jpg` と `back/paper-kraft.jpg`(ほぼベタ塗りなので繊維とムラを足す)、見本を含むその他の素材(manifest を検索)、一覧ボードと `preview.html`。
- `scripts/art-check.py` の「見本は4色」検査をやめ、彩度の上限とフチ合成テストに置き換える(見本1枚の容量は900KBまで)。

**守ること(従来どおり)**
- 題材ごとに候補を4枚つくり、参考画像に近く質感が静かなものを選ぶ。
- 12枚を並べて、**同じ手で描いたように**統一する。浮く1枚があれば作り直す。
- `GOOD DAY` と `Peta` 以外の文字・ロゴ・ブランドを入れない。レトロPCは初代 Macintosh に似せない。
- 原本と候補グリッドは `assets-src/art/`(Git 外)。コミットしない。
- アプリのコード(Rust / JS / HTML / CSS)は触らない。

**終わったら**
- 仕様書 §8 のチェックリストで自己点検し、`docs/art-restyle-report.md` に「差し替えた素材の一覧」と「直せなかった点」を書く。
- `npm test` と `git diff --check` を通し、`art: restyle samples — painterly illustration` で指定ブランチに push する。
