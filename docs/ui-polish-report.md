各素材に4候補を用意し、既存の Holographic カード・銀袋・封蝋・紙タブと並べて選びました。リボンは斜めに見える細かな織りの候補2、棚は静かな上面と積層断面の候補2、月タブは中央が静かな候補4を採用しました。接地影は短く静かな候補3です。

リボンはサテンの細い織り、両端の細い縫い目、暗い上端の折れ、V字の切り口のほつれを持ちます。赤はアクセントをこの布に限定しています。棚は厚紙の明るい上面、暗い前面、左右の積層した木口に相当する断面を持ち、文字や装飾は載せていません。上面を静かにして Pack を置けます。

月タブは右端用タブの流用をやめ、両上角を丸めて下端を真っ直ぐ差し込む上向き専用形にしました。5色は既存の厚紙タブのパレットに揃えています。ラベルは空白、月の名前はプレビューの HTML で重ねています。

原画・4候補・プロンプトと書き出し処理は `assets-src/art/ui-polish/` に保存し、Git対象外です。生成原画から切り出し、RGBA、紙／布の不透明度、影、色、sRGBと容量を正規化して書き出しました。棚の原画にあった彩色の外周フリンジは近傍の材質色に正規化し、ライト／ダークで確認しました。manifestに実寸、bytes、用途、プロンプト、採用候補、確認待ち状態、左右120pxの伸縮情報を記録しています。

## 旧版との比較

- しおり：旧版の CSS の光沢グラデーションと繰り返し横線に対し、新版は斜めの織り、縫い目、暗い挟み込みの折れを持ちます。幅24pxでも両端とV字を確認できます。
- 棚：旧版の紙テクスチャと陰影の帯に対し、新版は上面と前面の厚み、左右の積層が別々に見えます。Pack 下の影も茶色い CSS の楕円から、無彩色の薄い影画像へ置き換えた模型です。
- 月：旧版は右端用の紙タブを横向きに流用していました。新版は上角の丸みと下の接着線で、上辺に立つ形を読み取れます。高さ38pxで5色を並べました。
