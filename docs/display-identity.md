# 永続ディスプレイ識別

2026-10-06。macOSの保存先は `macos:<CGDisplayCreateUUIDFromDisplayIDのUUID>` に変更。`CGDirectDisplayID`そのもの、表示名、接続順、位置、解像度を永続IDとして保存しない。

TauriはネイティブのディスプレイIDを公開しないため、CoreGraphicsの論理原点をTauri/Taoと同じスケールで変換して現在のモニターに対応付け、そのUUIDを取得する。表示名の変更、並び替え、解像度/倍率の変更、再起動後もOSが同じUUIDを返す画面は同じ貼付先になる。メインディスプレイだけの変更も監視対象。

一意な対応付けができない場合は接続順による推測に戻さず、同期エラーとして処理する。ミラー表示や識別情報が重複するモニター/アダプターはこの制約に該当しうる。接続経路を変えたときのUUID維持はハードウェア・macOS依存のため実機確認が必要。Windowsの永続識別は今回の対象外。

## 旧データ

SQLite v7に更新。旧IDの表示名が現在の接続一覧で一意で、保存データにも `名前#2` などの同型画面の証拠がないときだけUUIDへ移行する。対応表は一度保存した後に別のUUIDへ付け替えない。同名モニターの曖昧さも記録し、片方を手動割当・取り外しした後で残りを誤って自動移行しない。剥がしたステッカーの保存先も移行し、座標・サイズ・角度・履歴・重なり順は保持する。

同型モニターの旧データには個体情報がないため、自動で正しい貼付先を復元できない。Collection詳細の **Home display** で接続画面を選び **Move** を押すと、選んだUUIDを貼付先にできる。今日の枠は使わない。新しいステッカーは最初からUUIDで保存する。

画面が未接続なら従来どおりメイン画面で一時表示する。そこで位置・サイズ・角度を編集しても未接続の元画面のIDは失わない。Home displayで明示的に変更した場合だけ新しい貼付先にする。

## Macでの確認

- 同型の外部モニター2台それぞれに貼り、ケーブルの接続順を入れ替える。元の物理画面に戻ること。
- 解像度・倍率・画面配置・メイン画面を変える。貼付先を維持し、相対座標で表示すること。
- 外部画面を外し、メインへ退避したステッカーを編集してから再接続する。元の外部画面へ戻ること。
- 旧データの同名画面は自動移行されず、Home displayで割り当てて再起動した後は戻ること。
- ミラー表示、USB-Cドック経由、接続ポート変更でUUIDを確認する。一意に取得できないケースのエラーと回復を確認する。

Linuxで実行するRustテストはID割当・旧DB移行・座標維持・曖昧な移行の拒否を検証する。CoreGraphicsの実際の戻り値はMac実機で確認する。
