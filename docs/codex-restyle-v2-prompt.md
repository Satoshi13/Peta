# Codex に送るメッセージ(見本ステッカー v2:AIっぽさを減らす)

そのまま貼り付けて送る。

---

先日の見本ステッカー12枚、質感は目標に近づきましたが、オーナーから「まぁまぁしっかりAIっぽい」と指摘がありました。診断と作り直しの方針を `docs/art-restyle-v2-spec.md` にまとめたので、これに従って作り直してください。

**AIっぽく見える原因(診断)**
- 12枚すべてに同じ油絵の筆跡がかかっている(素材ごとの質感の違いがない)。
- 描き込みすぎ(毛を1本ずつ描く、細かい反射)。ステッカーの絵としては情報量が多い。
- エナメルのようなツヤ(`good-day` `peta-bubble` `film-camera`)。
- 理想的すぎる光、整いすぎた形。
- `purple-scribble` が、指定のマーカーの一筆線ではなく立体のリボンになっている。
- `cat-skateboard` の縁(毛・しっぽ)がささくれている。
- `film-camera` が Leica M 型に近い。

**方針は「描き込む」から「見立てて省く」へ**
- 情報量を減らす(はっきり分かれた形は15個以内)。陰影は2〜3段で、なめらかなグラデーションにしない。
- **題材ごとに画材を変える**(ガッシュ・水彩・スクリーン印刷・マーカーなど。表は仕様書 §4)。ただし彩度・光(左上)・パレット・線の細さは揃え、並べて同じパックに見えること。
- 反射は小さく単純な形1か所まで。縁の光は禁止。
- 輪郭はすっきりさせる(ささくれ禁止)。

**やること**
1. **必須の5枚**を作り直す: `cat-skateboard` `purple-scribble` `good-day` `peta-bubble` `film-camera`。
2. **差し替え推奨の7枚**(`fried-egg` `blue-flower` `coffee-cup` `polaroid-mountain` `retro-computer` `potted-plant` `cassette-tape`)は4候補を出し、**新旧を並べて、より単純で人が描いた感じのほうを選ぶ**。旧版が良ければ残してよい(理由を報告に書く)。
3. 見本を使う素材(hero / cover-kraft / choice-collection / 一覧ボード / manifest / preview)を、既存スクリプトの入力だけ差し替えて作り直す。

**選び方が一番大事です**
- 4候補のうち、**一番きれいなもの**ではなく、**一番情報量が少なく、人が描いた感じのもの**を選んでください。
- ツヤ・縁の光・毛1本ずつの描き込み・完全な左右対称・縁のささくれがあれば落とす。
- 12枚を**50%の大きさで1列に並べ**、`docs/art-reference/style-target-stickers.jpg` の上段と比べてください。参考のほうが単純で平らに見えるなら、描き込みすぎです。

**使うプロンプト**: 仕様書 §3 の STYLE-sample v2 と NEGATIVE、§4 の題材ごとの `{MEDIUM}` とプロンプト。従来の STYLE-sample(`art-restyle-spec.md` §4)と §5 の題材プロンプトは、これで**置き換え**です。

**後処理**: `scripts/art-humanize.py` は、実験で効果が小さかったので**原則使わない**でください(使うなら強さ0.5まで、並べて確認)。

**従来どおり**: 寸法(長辺1024px・8px余白)、白フチ・接地影・背景を付けない、`GOOD DAY` と `Peta` 以外の文字・ロゴを入れない、`art-check.py` / `npm test` / `git diff --check`、原本は `assets-src/art/`(Git外)、アプリのコードは触らない。

**終わったら**: 仕様書 §8 のチェックリストで自己点検し、`docs/art-restyle-v2-report.md` に「5枚と7枚それぞれ、作り直したか旧版を残したか、その理由」と「直せなかった点」を書いて、`art: restyle v2 — simpler, less AI-looking samples` で指定ブランチに push してください。
