# 本物と複製・Gift v3 実装報告

2026-10-11。機能に必要な UI を実装し、見た目の仕上げは含めていません。

## 作ったもの

- DB V12：既存行を real/held に移行。複製・入力 SHA-256・作者の署名・完成画像の指紋・移動記録・未検証・受領待ちの claim を追加しました。V1〜V11 のマイグレーションは維持しています。
- 作者の証明と release/claim を既存 Ed25519 で検証します。画像・作者・順番・持ち主・参照先・逆行/未来の日時をチェックします。
- 無料の Duplicate（合計10枚）。本物の画像を共有し、複製からの複製も本物に集約。削除/移動で子の複製と配置・タグを整理します。Gift/Pack は Rust でも copies_stay_home で拒否します。
- Gift v3 は番号なしの譲渡。保存失敗と Referee 拒否で巻き戻します。ファイルの上書きは一時ファイル・旧ファイルの退避・復旧ジャーナルで扱い、起動時に確定した DB 記録と照合します。
- 別 Library への受領・開封・送り返しをテストし、同じ ID で元の行が戻ることを確認しました。受領時に claim、開封時に本物・日次記録・印刷待ちを同じトランザクションで確定します。
- v1/v2 を引き続き受領でき、作者は未検証です。旧データを転送するときにも作者の署名を捏造せず、現持ち主の引継ぎ証明を付けます。
- seen_sources は削除で消えません。作成結果に newImage を返し、空の scraps::on_new_sticker を呼びます。素材違いの作成と開発者版でも計算します。既存原本の編集結果は newImage=false です。
- Collection の複製数・まとまり・個別詳細・枚数選択、未検証表示、Studio の複製除外、Gift の明示的な確認を追加しました。

## 検証

Rust workspace と JS の回帰テスト、macOS の型検査を実施しました。V11→V12 の保持、署名/連鎖の拒否、複製上限/共有/削除、移動/送り返し、ファイル失敗/拒否の巻き戻し、v1/v2、画像の指紋とボーナスの口、保存復旧をテストしています。Vision を使うテストは macOS ハードウェアにアクセスできる環境で実行しています。

## 守れないこと・実機で確認すること

審判がない間は、同じ Gift ファイルを複数人が受け取ることを防げません。連鎖は署名つきの証拠であり、強制ではありません。NoReferee は全てを通します。Scraps の支払いとサーバーは未実装です。

オーナーの写真・実際の2インスタンス間のファイル受け渡し・デスクトップの複製操作・保存ダイアログは、`port-spec/macos-checklist.md` の項目で確認してください。テスト用の別 Library による往復は確認済みですが、実操作を済み扱いにはしていません。
