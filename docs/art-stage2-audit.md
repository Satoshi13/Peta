- **範囲**: Rust・JS・HTML・CSS は触っていない(素材・制作スクリプト・プレビュー・マニフェストのみ)。原本は Git 外。合計 6.1MB。

## 作り直し(Codex へ)

1. **紙テクスチャが実質ベタ塗り(`back/paper-cream.jpg`, `back/paper-kraft.jpg`)**
   明度の標準偏差が **0.52**(値の幅 238〜242 / 170〜173)で、目で見える繊維・ムラがない。指定は「繊維と微細なムラ」。
   同じクラフトでも `arrival-material.png` は標準偏差 **31**、参考画像の裏面カードも紙の表情が豊か。このまま裏面に敷くと、封筒・表紙と並べて**平らなプラスチックに見える**(表紙・封筒との整合も崩れる)。
   → 標準偏差 3〜6 程度で、繊維・粒・ごく薄い雲ムラを足す。継ぎ目なし(1024)は維持。クリームは #F5F0E6、クラフトは #C9A878 の平均色を保つ。
2. **ヒーロー(`onboarding/hero.png`)の構図が散らばっていない**
   見本4枚が**四隅に離れて**置かれ、ただの「角に絵がある紙」に見える。指定は「3〜5枚が散らばって貼られている」、参考画像は**重なり・傾き・密度**がある。
   → 5枚、重なりを少し許し、傾き ±10°、中央の余白は維持(ロゴ用)。紙の端に影か切れ端を足して「紙の上に貼った」感じを出す。

## 要確認・軽微(直さなくても進められる)

- **台紙の比率**: `print/backing-sheet.png` は 1000×1500(2:3)の縦長。アプリ側で作った台紙(Collection の表裏・Print)は 4:5 のカード。→ **組み込み時にこちらで寸法を決める**(2:3 を使うか、4:5 を依頼するか)。裏面の紙(`paper-cream`)と同じ紙として並べるには、上記の1.の直しが先。
- **`samples/retro-computer.png`**: 初代 Macintosh の輪郭に近い(ロゴはない)。今のアプリ内用途では問題なし。**公開・配布前に**、角丸や画面の形を少し変えて既視感を下げると安全。
- **`back/torn-edge-mask.png`**: 縁がやや規則的なギザギザで、`arrival-material` の自然な破れより機械的。
- **`empty/nothing-to-peel.png`**: 剥がれた角が小さく、暗い面だとほぼ見えない。
- **`fried-egg` / `coffee-cup`**: 白い面の中に細かい粒状のノイズ(ラテアートの白、黄身の傷)。他の見本より少しだけ荒い。許容範囲。
- **`gift/mystery-sticker.png`**: 暗い背景ではグラシンが灰褐色に沈む。パステルの光はごく小さい。明るい面のほうが映える。
- **ボード内の配置**: `print/print-slot.png`(細い線)と `print-slot-glow.png`(alpha 最大 26)は単体だとほとんど見えない。加算合成前提なので、組み込みの際に確認する。
