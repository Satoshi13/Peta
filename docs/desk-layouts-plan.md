# 机の飾り方(台紙に配置を保存して切り替える)要件

決定日: 2026-10-12(オーナー)。**要件の記録で、実装は未着手**。作業順の①「ツール」の1つ(見せる道具)。見た目の叩き台はオーナーのラフ(Desk のページに台紙が3枚並び、右に Tools の「台紙 1枚」)。

## ひとことで

いまデスクトップに貼ってあるステッカーの並びを**台紙に保存**し、あとで**ワンクリックでその並びに戻せる**。台紙の枚数は最初 2 枚。足りなければ Market の Tools で **Scraps と交換して1枚ずつ増やす**。

## 決めたこと(オーナー、2026-10-12)

1. **切り替えると、いまのステッカーは全部剥がして台紙どおりに貼る**(足すのではなく置き換える)。直前の配置は自動で1つ取っておき、Undo で戻せる。
2. **保存したときのディスプレイがつながっていなければ、その分はメインのディスプレイの同じ相対位置に寄せる**。台紙の中身(どのディスプレイか)は書き換えないので、つなぎ直して切り替えれば元の場所に戻る。これは今のデスクトップの動き(`layers.rs` の `placements_for`)と同じ。
3. **無料の台紙は 2 枚**。3枚目から Tools の「Mount ×1」。
4. **メニューバーから切り替えられる**(`Desk ▸` のサブメニュー)。

## 保存するもの

- 台紙1枚 = 名前 + 「どのステッカーを・どのディスプレイの・どこに・どの大きさ/角度/重なり順で」の一覧。今の `placements` の行(`display_id`・`relative_x/y`・`relative_scale`・`rotation`・`z`)をそのまま写す。
- **保存するのはステッカーへの参照だけで、コピーは作らない**。同じステッカーが複数の台紙に載ってよい。デスクトップに出るのは一度に1つの台紙なので、「本物は1枚」(`decisions.md` 2026-10-11)とぶつからない。
- 飾り用の古い複製(`lineage='copy'`)も載せられる(手元から出ないもの)。
- リンクタグは**保存しない**(ステッカーに付いているもので、配置ではない)。切り替えてもタグは付いたまま。
- 名前: 24文字まで。既定は `Desk 1`、`Desk 2`…。表示は手書き風(ラフどおり)。
- 空のデスクトップは保存できない(「Stick something first」)。

## 台紙の絵

- ステッカーの画像を縮小して、台紙の紙の上に保存した配置で並べ直して描く(ディスプレイが複数なら、横に並べた全体を縮める)。
- **画面のスクリーンショットは使わない**(壁紙・デスクトップのファイル名・他のアプリが写り込むため)。
- 描画はページ側。保存はしない(開くたびに描く。重ければ縮小画像をキャッシュ)。

## 切り替え(「Use this layout」)

1. いまの配置を「直前の配置」として取っておく(1つだけ。台紙の枠は使わない)。
2. いま貼ってあるステッカーを全部剥がす(`peel` と同じ。ステッカーは Collection に残る)。
3. 台紙の一覧を順に貼る(`place`)。**Print → Grab → Paste の儀式は通さず、その場で貼る**。
4. **手元にないステッカーは飛ばす**(Gift で送った・パックに入れた・削除した)。「2 stickers are no longer yours」と短く出す。台紙の絵では点線の影で示す(削除したものは影も出さない)。
5. 全部を1つのトランザクションで行う。途中で失敗したら、元の配置のまま。

- **切り替えは「今日の1枚を貼った」に数えない。Scraps も動かない**(毎日の記録・報酬を切り替えで稼げないように)。印刷待ちの列は触らない。
- **Undo**: 切り替えのあと、Desk のページとメニューバーに「Undo」(次に配置を変えるまで)。
- 切り替えの演出は控えめに(剥がれて、貼られる)。Reduce motion では省く。

## 使っている台紙の印と、上書き

- いまのデスクトップが台紙と同じなら、その台紙にチェック(ラフの緑のチェック)。
- 手でステッカーを動かす・足す・剥がすと、チェックは `Edited` に変わる。そのとき「Update this layout」(上書き)と「Save as new」(空き枠があるとき)を出す。
- 判定は「台紙の一覧と、いまの配置が同じか」(位置は少しの誤差を許す)。

## 枠(台紙の枚数)と Tools

- 最初から使える枠は **2**。上限は **12**。
- 3枚目からは Market の Tools に「**Mount ×1** — Adds one more saved layout」。Scraps と交換すると枠が1つ増える(**永久**。台紙を消すと空き枠に戻る)。
- **値段は②「Scraps の経済」で決める**。実装では値段を1か所の設定値にする(リンクタグと同じ扱い)。
- 枠は人に渡せない(Gift・パックの景品にしない)。台紙そのものも共有しない(相手の持っていない本物を指すため)。
- 枠がいっぱいのときに「Save current layout」を押すと、Tools の Mount へ案内する(押し売りしない文言で)。

## 画面と入口

- **Desk のページ**(サイドバーに追加。置き場所はデザイン担当と決める): 台紙の一覧(名前・絵・チェック)、「Save current layout」、各台紙の「Use this layout」と「…」(名前を変える・上書き・削除)、右に Tools の Mount のカード(ラフどおり)。
- **メニューバー**: `Desk ▸` に台紙の名前を並べ、使っているものにチェック。最後に「Undo」と「Save current layout…」。
- 削除は確認を出す(ステッカーは消えないことを書く)。
- 文言は英語(アプリの方針)。ラフの日本語は意味の目安。

## データ(実装時に確定)

- DB の追加は、そのときの最新の次の版(S1 が V14 を使うので、その後)。例: `desk_layouts(id, name, sort, created_at, updated_at)`、`desk_layout_items(layout_id, sticker_id, display_id, relative_x, relative_y, relative_scale, rotation, z)`、枠の数は `meta` の `desk.slots`、直前の配置も同じ形で1つ。
- ステッカーを削除したら、台紙からも外す。Gift やパックで手放したもの(`state='gone'`)は台紙に残し、切り替えのときに飛ばす。
- ディスプレイの ID は今の仕組み(名前ベース、`layers.rs` の `assign_display_ids`)を使う。同じ機種の外部モニターを2台入れ替えると取り違える既知の弱点がある(`TODO(phase 1)`)。台紙もそれを引き継ぐ。

## 最初はやらないこと

- 時刻・曜日・ディスプレイの接続での自動切り替え(「外部モニターにつないだら Work day」など)。人気が出たら次の Tools 候補。
- 台紙の共有・友達への公開。
- 台紙ごとの壁紙。
