# 現段階のバグ点検・修正

2026-10-12。対象は直近の Vision、Gift v3、有限版 Pack、Duplicate 廃止、Studio / My shelf の実装と、それにつながる画面・画像キャッシュです。

## 見つかった不具合と修正

| 不具合 | 起きる条件 | 修正後 |
| --- | --- | --- |
| 保存済みなのに Seal の失敗として扱われる | 保存成功後の状態取得が失敗 | native 保存の成功直後に完成状態・保存先を記録し、下書きを消す。表示更新の失敗で譲渡・press をやり直さない |
| Seal 中に選択内容や完成画面が変わる | native の変更通知・画面移動と封入が重なる | 開始時のモード・引数を保持。封入中の再描画・下書き再読込・ページ移動を抑制 |
| 完成済みパックが下書きに戻る | 完成後に別の Gift 下書きを保存 | 完成済みの Pack / Gift は下書きに含めず、再読込でも上書きしない |
| 保存ダイアログで本体が隠れる | 外側クリックで閉じる設定と native 保存ダイアログ | Gift 送信・Pack 保存・棚からの書き出し中はダイアログとして扱い、終了・キャンセル・失敗後に戻す |
| 開封済みなのに開封失敗と表示される | Gift / Pack の開封成功後、詳細取得・状態更新・画像表示が失敗 | 受領・残数・無料枠の消費を先に記録。確定済みの結果は保持し、表示を閉じて Collection / stock または印刷待ちから利用できる |
| 開封画面から戻れなくなる | Stick it / Gift の Later / 印刷の失敗、取得中の Esc、ボタン連打 | busy と画面を片付ける。詳細取得前の Esc を待機させ、完了操作は一度だけ実行。開封後の Gift は Esc で Later にできる |
| 画像が表示されなくなる・古い画像に戻る | 一時的な画像取得失敗、編集直後に古い取得結果が到着 | 失敗した取得を再試行可能にし、Studio もキャッシュを無効化。古い成功・失敗が新しいキャッシュを上書き・削除しない。共有 URL の重複解放も防ぐ |
| 10枚開封だけ装飾が反映されない | まとめて開く画面が独自の包装描画を使う | 同じ BagPic の表紙・保存済みの配置・装飾を表示。kraft / matte / holo は同じ装飾を各 tear layer に反映し、それ以外の5包装は本来の包装をクリック・ドラッグ・Enter で開く |
| 設定の破損で起動できない | preferences が不正 JSON / null / 配列、ストレージへのアクセス失敗 | メイン画面とデスクトップ層が既定設定で起動できる。設定の保存失敗も画面の更新を妨げない |
| 失敗した受信・開封・棚保存の画像だけ残る | Gift の claim 拒否・印刷初期化失敗、Pack の SQL / commit / ファイル保存失敗 | 画像・mask・受信ファイルを復旧ジャーナルで管理。DB と同じ transaction の一意な receipt で確定し、失敗時は新規ファイルを除去、既存ファイルを復元 |
| 書き出し途中の一時ファイルが残る | temp 作成後、復旧ジャーナルの作成・書込・sync が失敗 | temp と途中の journal を片付けて返す。既存の保存先は変更しない |

10枚開封の非同期プレビューも、画面を閉じた後は表示用データの更新を止めます。

- native の検証には、既存ファイル復元、新規画像除去、receipt の SQL 失敗、遅延外部キーによる commit 失敗、Gift の claim / 印刷失敗、Pack の棚保存 / press 失敗、復旧ジャーナルの作成失敗を含みます。署名・所有権・版の既存テストも成功。
