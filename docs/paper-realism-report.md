対象ブランチは `claude/relaxed-dijkstra-ocnjzu`、基点は `b22a654`。指定の触れるプロトタイプをブラウザで開き、A Notebook / B Desk / C Studio を切り替えて確認しました。プロトタイプの CSS・JS・HTML と、アプリ実装は変更していません。比較模型は `src/art/preview.html` の専用セクションだけに追加しています。

## 旧版と並べた所見

旧 A のタブは、均一な角丸と上から下へのグラデーションが形を支配していました。新版は切り口の淡い断面、色ごとに違う小さな縁の揺れ、繊維、左の接着線を加えています。高さ46pxで7色を並べ、断面と短い接地影を確認できます。紙面は不透明です。

旧ページは均一なクリームのベールと等間隔の点が主に見え、新版は細い繊維と微かな雲状のムラが見えます。ドットは比較模型の CSS で同じ22px間隔を重ね、紙自体の違いを比較しています。新しい紙画像にはドットを入れていません。

表紙の厚紙には長い淡い繊維、小さな暗い粒、非常に薄いエンボス格子があります。元の一枚の茶色い面より素材が読める一方、擦れた芯材・摩耗した角・小口はこの段階では加えていません。スプリング画像はバイト単位で維持し、同じ左上の光の紙と並べています。

比較模型は既存素材を縮小して載せています。文字はすべて HTML、紙上の本文は14pxです。ライト・ダーク・壁紙風で新タブの外周に白黒ハローや市松の焼き込みは見えませんでした。最終的な繊維量・色の濃さ・現実味の判断はオーナー確認待ちです。

## 既存ノート素材の扱い・残っている点

| 既存素材 | 今回の判断 | 理由 |
|---|---|---|
| spiral-binding / coil / holes / caps / graphite | 維持 | オーナー指定どおり、今回の改善対象外。元の綴じ・光・周期を維持 |
| cover-kraft.png | 維持 | 青い花・既存構図は残す。新しい厚紙が承認された後、摩耗・断面の cover-edge と一緒に更新の要否を判断 |
| page-right.jpg / page-left.jpg | 維持 | 元の紙・ドット・穴を持つ完成素材。今回は独立した紙テクスチャの確認に限定 |
| notebook-page.png | 維持 | 既存の9スライス小口を持つ完成素材。新しい小口・gutter が揃った段階で統合の要否を判断 |
| page-paper.jpg | 置き換え | 指定された1024×1024・継ぎ目なしの無地紙として納品。旧版は比較資料へ保存 |

既存 Collection の `art/p1.css .page` は同じ `book/page-paper.jpg` の URL を使うため、画像の差し替えで紙背景が新しくなります。旧画像内のドットは含めていません。独立した `page-dots.png` は次段階なので、紙＋ドットの実装統合は未完了です。触れるプロトタイプは独自の既存紙を参照しており、今回の納品をまだ適用していません。

この段階では表紙の摩耗・紙束の40枚ほどの厚み・綴じ側のたわみを直したとは扱いません。フィルムとマステの2案目・3案目、メモ類、Peta! タグも、紙タブと紙の方向性を確認いただいてから進めます。
