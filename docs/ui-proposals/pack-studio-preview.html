Pack Studio

いまの「Make a Pack…」はモーダルの2ページ(選ぶ → 名前と袋を決める)で終わります。これを、ページ全体の作業台にして、袋そのものを触りながら作り込めるようにしたプレビューです。左の袋はいつも見えていて、右の道具で変えたことがすぐ袋に出ます。工程は自由に行き来できます。

袋はドラッグ(傾く・光る)、ステッカーや飾りは袋の上へドラッグ、ホイールで拡大、Shift+ホイールで回転。

何を変えたか

今(モーダル)

  • 3〜24枚をチェックボックスで選ぶ
  • 名前・袋の種類(3つ)・各ステッカーの名前とレア度をフォームで入力
  • 袋が見えるのは、作った後だけ
  • 全部が「入力して保存」で、作り込む余地がない

Pack Studio(このプレビュー)

  • 袋がずっと見えている。触れる(傾く・光る)し、入れたステッカーが袋の口から覗く
  • Sort:レア度の棚へステッカーをドラッグ。出やすさはアプリ本物の重み(60/30/10)で計算して、棚の下に実数を出す
  • Dress:袋・色・ラベルの形・口のテープ・表紙ステッカー・飾り(クリップ/ピン)を袋の上で配置
  • Seal:棚とMarketでの見え方を確かめてから、封をする演出で完成

実装に必要なもの(今のアプリで足りないもの)

そのまま使える 今ある

  • タイトル(40文字)、袋の種類3つ、3〜24枚、各ステッカーの名前とレア度、署名つきの保存
  • レア度の出やすさ(common 60 / uncommon 30 / rare 10、空の等級は残りで按分)

パックの形式に項目を足す データ

  • 色(hue)、ラベルの形、口のテープ、表紙ステッカー、飾りの位置、紹介文(Marketのカードに出す)
  • どれも署名の対象に含める(受け取った側で見た目が変わらないように)

素材の追加 アート

  • ラベルの形(スタンプ・マスキングテープ・タイプライター)を紙の画像で
  • 口のテープ数種(マスキングテープ)、飾り数種(クリップ・ピン・しおり・小さな札)
  • 封をする金属の押さえ(今回は仮の絵)

まず Gather → Sort → Dress → Seal の順で触って、「ここは要らない」「ここをもっと作り込みたい」を教えてください。次のどれから実装するかを決められます。
