Peta · Make a Pack

Studio — Pack & Gift

Make のタブに「Studio」を追加するプレビューです。最初に Pack(Market・友だち向けのセット)か Gift(1人に渡す1枚)を選び、ページ全体の作業台で、袋そのものを触りながら作り込みます。左の袋はいつも見えていて、右の道具で変えたことがすぐ袋に出ます。

袋はドラッグ(傾く・光る)、ステッカーや飾りは袋の上へドラッグ、ホイールで拡大、Shift+ホイールで回転。

何を変えたか

今

  • Make は「Create」(ステッカーを作る)だけ
  • パックは Collection の「Make a Pack…」からモーダルで作る(2ページ、袋は3種)
  • ギフトは1枚ずつ、Collection の詳細から「Gift…」

Studio(このプレビュー)

  • Make に「Studio」を追加。最初に Pack か Gift を選ぶ
  • Pack(Marketや友だち向け):Gather → Sort → Dress → Seal。レア度の出やすさは本物の重み(60/30/10)
  • Gift(1人向け):Choose → Wrap → Write → Seal。宛名と一言を書き、受け取り側の見え方も確かめる
  • 袋は Codex の汎用素材12種 + 今の3種。ラベルは各素材の空白の紙の位置に載る

実装に必要なもの

今のまま使える 今ある

  • パック:タイトル・袋の種類・3〜24枚・各名前とレア度・署名つき保存、ギフト:宛名・一言・署名つきファイル

形式に足す データ

  • 袋の種類を3つ → 15種に(素材ID)、色、ラベルの形、口のテープ、表紙、飾りの位置、紹介文
  • ギフトにも包みの種類・飾りを持たせ、受け取る側で同じ見た目にする(署名の対象)

素材 アート

  • 12種の汎用素材は届いた(位置は manifest から)。1枚画像なので、袋の前面/背面の重なりや、口から覗く演出は近似です
  • ラベル/マステ/飾りの種類は、あとで素材を足す

Pack と Gift を同じ作業台にするのは、Seal・Dress が共通だからです。違うのは、中身(複数 or 1枚)と、渡し方(Market・棚 or ファイル)だけです。実際に触って、「Pack/Gift の分け方」や「素材の合わせ方」の感触を教えてください。
