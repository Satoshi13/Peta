Studio — Pack & Gift

Make のタブに「Studio」を追加するプレビューです。最初に Pack(Market・友だち向けのセット)か Gift(1人に渡す1枚)を選び、ページ全体の作業台で、袋そのものを触りながら作り込みます。左の袋はいつも見えていて、右の道具で変えたことがすぐ袋に出ます。

見どころ: ステッカーを選ぶと袋に飛び込む / 袋ごとに封じ方が違う(Seal) / 袋は実寸の比率で、台の定規は cm / 袋に触れると影が追う / 光は時間帯。

世界観: 実写の物 × フラットなシステムUI

触れる物は実写、決める部分はシステムUI、と分けています。UIは質感を持たず(右上の「UI」で、紙の質感の今の見た目と見比べられます)、色と質感はすべて物から出ます。

動き

  • ステッカーが袋に飛び込む(外すと戻る)。袋が少し沈む
  • 封じ方が包みごとに違う: 金属プレス(ホログラム)/ テープを貼って親指でなぞる(Kraft・Matte・Parcel・Pocket)/ 丸いシールを押す(Glassine・Folded wrap)/ フラップを閉じて親指でなぞる(Photo・Airmail)/ ひもを引き絞る(Cotton)/ スリーブを押し込む(Drawer)
  • 封をした袋は、不透明なものは中身が見えなくなる(グラシンと折り包みは透けたまま)。テープやスリーブも付いたまま

現実に寄せたところ

  • 実寸の比率: 袋ごとに幅(cm)を持ち、台の定規(cm)と合わせて描く。棚の上でも同じ縮尺
  • 個体差: ラベルの傾き・位置、テープ、表紙、クリップの角度が、パックごとにわずかに違う(名前から決まるので、いつも同じ)
  • 影が傾きに追従、グラシンや折り包みには光の反射
  • 光は時間帯(右上の「光」で 朝・昼・夕・夜 を切り替え、既定はいまの時刻)
  • Market の見せ方: 吊るもの(Kraft・Matte・Holo・Glassine・Cotton)はレールに、立つもの(封筒・箱・包み)は台に立てかけて表示
  • ラベルの文字は、手書き(ペン)とタイプライターの組み合わせ

まだ近似のところ(Codexに頼むと良くなる)

  • 袋は1枚画像なので、封じ方は画像の切り出しや重ねで近似しています。前面・背面・フラップ・留め具を分けた素材があると、剥がす・解く・開ける演出が本物になります
  • 袋の厚み(3枚と24枚で変わる)は未対応。厚み3段階の素材が必要です
  • 音は仮の合成音。素材ごとの録音(紙・グラシン・布・フォイル)に差し替えたい

仕様(選ぶだけ・数字は持たない)

座標や色相のような自由な数値は持たず、袋・表紙・飾りは「ID」を選ぶだけにしました。位置は包みごとに決まっているので、どの組み合わせでも整い、署名にも入れやすく、受け取った側でも同じ見た目になります。Pack も Gift も「中身 → 見た目 → 封」の3工程です。

Pack

  • 枚数 3〜24枚
  • 出やすさ ステッカーごとにタップで Common → Uncommon → Rare。Rare は全体の1/3まで。確率は「いちばん出にくい1枚は 1/N」の1行だけ(重みは本物の60/30/10)
  • 包み 8種(今の3種 + Glassine・Kraft parcel・Library pocket・Drawer box・Cotton pouch)
  • 名前 全角14文字まで・ラベルに1行で自動縮小。ラベルは紙の1種類だけ
  • 表紙 中のステッカー1枚か、なし(位置は包みごとに固定)
  • 飾り なし / クリップ / ピン / テープ のどれか1つ(位置は固定)
  • 紹介文 60文字まで・Market のカード用。封の画面で書く

Gift

  • 中身 ステッカー1枚(今の形式のまま)
  • 包み 6種(Airmail・Photo envelope・Kraft parcel・Folded wrap・Cotton pouch・Glassine)
  • 宛名 全角14文字まで(必須)
  • 一言 80文字まで。開けた人にだけ見える
  • 飾り Pack と同じ

共通

  • 封をしたら変更できません(編集に戻れるのは封をする前まで)
  • 下書きは Pack と Gift で1つずつ。自動で保存
  • 署名に入るのは ID と文字だけ(包み・表紙・飾り・名前・紹介文/宛名・一言)
  • 封の画面で、Pack は「棚と Market」、Gift は「届いたとき と 開けたとき」を並べて確認
  • 各工程の主ボタンは右下の1つだけ

やめたもの

ステッカーのドラッグ配置・ホイールで拡大・回転、色相スライダー、ラベル4種(スタンプ・テープ・タイプ文字)、口のテープ6種、飾りの複数置き、確率の表、レアの棚へのドラッグ、Foil・Cellophane・Belly band・Mini folio(ラベルや表紙を載せにくい、またはホログラムと被る)。

実装に必要なもの

形式に足す データ

  • Pack に、包みID・表紙ID・飾りID・紹介文(署名の対象)
  • Gift に、包みID・飾りID(同じ)
  • 名前と宛名の上限を全角14文字に(今のコードの上限と要照合)

素材 アート

  • 汎用素材は届いています。位置(ラベル・表紙・飾り)は包みごとの表にして持ちます
  • 1枚画像なので、袋の前面/背面の重なりや、口から覗く演出は近似です

ここから後で足せる自由度の候補: 表紙の位置を、包みごとに3か所から選ぶ。反応を見て決めます。
