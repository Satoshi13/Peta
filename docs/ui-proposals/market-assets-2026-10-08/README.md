# Market 素材の納品（2026-10-08）

写実的な文具と洗練されたシステム UI を組み合わせた Market の見本を元に、
①コルクボード、②紙クリップ、③レールの棒、④吊りクリップ、⑤メモの紙、⑥左右の端を独立して描き直しました。
吊りクリップは、斜めに見えていた挟み板を正面に修正した版です。

全 7 点の透明 PNG、長辺 2400px 以上、コルクボードの 3:1、棒の左右端の RGBA と隣接列の一致を確認しました。
生成原本を拡大・透過の縁を清掃した納品版で、ネイティブ 2400px の生成ではありません。
原本と納品 ZIP は Git の外に保存しています。プレビューにある文字・背景は PNG 素材には含まれません。
`npm test` は 75 件すべて合格。納品 ZIP の CRC とドキュメントのリンクも確認しました。

このコミットは素材の追加です。Market の表示への接続や画面遷移時の揺れは、今後の実装に使える提案です。
