なぜ安っぽく見えるか

・パックや封筒は「紙の実物」なのに、この部分だけ Webフォームの部品(ピル型のチップ、罫線リスト)。

・レアリティが小さなバッジで、「出た!」感が無い。

→ 下の3案は、すべて「素材=手に取れる紙もの」として扱い直しています。

3. Codex に頼めそうなアート (今あるものだけでも上の案は成立。足すともっと良くなるもの)

好きだと言っていた「パックのデザイン」と同じ筆致で追加できそうなものです。docs/codex-art-prompt.md の STYLE LOCK を流用できます。

レアリティ・シール一式common / uncommon / rare / special / archive の5枚。Rare=ホログラム、Special=シルバー箔、Archive=古い紙の消印。文字はコードが重ねる。→ 案A/Bの Rare 表示が一気に本物になる。
素材カードに「選択中」用の台紙・トレイへこんだ木/紙のトレイ、カード用の透明スリーブ(グラシン)。選択=スリーブから半分出る、にもできる。
未獲得素材のシルエットMaterial Book の「???」用に、紙にエンボスだけ残ったようなカード。獲得すると中身が入る演出もできる。
素材別パック今の pouch(ホログラム袋)の色違い:Kraft=紙袋、Matte=クリーム封筒、Holographic=銀。レアリティで袋が変わると「開ける前から期待」が生まれる。
紙の小物パーツホール付き荷札(案B)、ポケット前板(方向3)、ゴム印の日付枠、色違いのマステを5〜6種。
ボタン用の紙パーツOpen / Make this Peta を押せる「ラベルシール」風ボタン(通常/押下の2枚)。いまの黒いピルだけが画面で唯一"UI部品"として浮いている。

4. 選び方の目安

実装が軽い順: C < B < A(ほぼ CSS+既存画像。新規アート不要) 世界観が強い順: 方向3 > 方向2 > 方向1 仕様リスク: 方向3 の手書き見出しだけ要確認

組み合わせ例:「素材UI = A」+「全体 = 方向1」を最初の一歩にして、反応を見ながら方向2/3へ寄せる。
