# Peta の Discord サーバー 草案

2026-10-14。友達だけのベータを、ゲームの公式サーバーのような形で運営するための草案。**サーバーの作り方(§1〜§4)**と、**そのまま貼れる文面(§5)**、**運営の流れ(§6)**に分かれる。文面の中の `【】` はオーナーが埋める所。

---

## 0. 方針

- **招待制・友達だけ**。サーバーの公開(Discord の「サーバーを見つける」)はしない。招待リンクは期限と回数を付けて、1人ずつ渡す。
- **入口は1本**: ダウンロード → はじめかた → 困ったらヘルプ → 気づいたらバグ報告・要望、の順に、上から読めば迷わない並びにする。
- **アプリの文言は英語、サーバーは日本語**。案内ではボタン名を英語のまま書く(`Copy code` など)ので、画面と照らし合わせやすい。
- **人数が少ない前提で軽く**: ロールは3つ、ボットは入れない(必要になってから)。
- **秘密は貼らない**: 鍵のバックアップ(`.petakey`)、移行ファイル(`.petamove`)、パスフレーズは、どのチャンネルにも貼らない(§5.1 のルールに書く)。

## 1. チャンネル構成

絵文字はカテゴリ名の飾り。好みで変えてよい。

| カテゴリ | チャンネル | 種類 | 誰が書ける | 用途 |
|---|---|---|---|---|
| 📌 はじめに | `#ようこそ` | テキスト | 運営だけ | ルールと各チャンネルの案内。最初に読む所 |
| | `#お知らせ` | アナウンス | 運営だけ | 新しい版・障害・メンテナンス |
| | `#ダウンロード` | テキスト | 運営だけ | 最新版のリンク・入れ方・更新のしかた |
| | `#はじめかた` | テキスト | 運営だけ | 名前・友達・Gift・Market の最初の一歩 |
| 💬 みんな | `#雑談` | テキスト | 全員 | なんでも |
| | `#作品を見せる` | テキスト | 全員 | 作ったステッカーやデスクトップのスクショ |
| | `#パックの宣伝` | テキスト | 全員 | 「Market に出したよ」の告知。1パック1投稿 |
| | `#フレンドコード` | テキスト | 全員 | 友達コードの交換(§5.5) |
| 🛟 サポート | `#よくある質問` | テキスト | 運営だけ | FAQ(§5.6)。ヘルプの前に見てもらう |
| | `#ヘルプ` | フォーラム | 全員 | 困りごと1件につき1投稿(§2) |
| 🐞 フィードバック | `#バグ報告` | フォーラム | 全員 | 不具合1件につき1投稿(§2) |
| | `#要望・アイデア` | フォーラム | 全員 | 「こうだったらいいな」。リアクションで票 |
| | `#変更履歴` | テキスト | 運営だけ | 版ごとの変更点(§5.9) |
| 🔊 通話 | `作業通話` | ボイス | 全員 | もくもく作業・画面共有での相談 |
| 🔒 運営 | `#運営メモ` | テキスト | 運営だけ(見えるのも運営だけ) | 対応中のこと・次の版の予定 |
| | `#通報通知` | テキスト | 運営だけ(見えるのも運営だけ) | Peta の通報の Webhook の行き先(§3) |

- **フォーラム**にすると、1件ずつスレッドになり、タグで状態を管理できる。フォーラムが作れない場合は、サーバー設定で「コミュニティ」を有効にする(有効にしても、公開されるわけではない。公開は「サーバーを見つける」を別に有効にしたときだけ)。
- 「運営だけ書ける」は、チャンネルの権限で `@everyone` の「メッセージを送信」をオフ、「運営」ロールでオンにする。
- `#お知らせ` をアナウンスチャンネルにすると、運営の投稿を目立たせられる(コミュニティ機能が要る)。普通のテキストでもよい。

## 2. フォーラムのタグとテンプレート

### `#ヘルプ`
- タグ: `インストール・起動` / `友達・フレンドコード` / `Gift` / `Market・パック` / `Scraps` / `データ・移行` / `その他` / `解決済み`
- 投稿のガイドライン(フォーラムの「投稿ガイドライン」欄に貼る):

```
困っていることを1件ずつ投稿してください。
・何をしようとしたか
・何が起きたか(画面の英語の文言をそのまま書いてもらえると助かります)
・スクショ(友達コードや名前が写っていても、このサーバーの中なら大丈夫です)
解決したら「解決済み」のタグを付けてください。
※ .petakey / .petamove のファイルやパスフレーズは貼らないでください。
```

### `#バグ報告`
- タグ: `新規` / `確認中` / `再現できた` / `修正済み・次の版` / `リリース済み` / `再現できず` / `仕様`
- 投稿のガイドライン:

```
1件につき1投稿でお願いします。タイトルは「何がどうなるか」を短く(例: Market で Pull を押すと固まる)。

【使っている版】ダウンロードしたファイル名(例: Peta-0.1.0.dmg)
【Mac】機種と macOS の版( → この Mac について で見られます)
【起きたこと】
【やったこと(手順)】1. … 2. … 3. …
【本当はどうなってほしいか】
【いつ頃】(日時。サーバー側の記録と照らし合わせます)
【スクショ・画面の文言】

※ .petakey / .petamove のファイルやパスフレーズは貼らないでください。
```

### `#要望・アイデア`
- タグ: `作る` / `Gift` / `Market` / `素材・Scraps` / `デスクトップ・Boards` / `その他` / `検討中` / `やる` / `見送り`
- ガイドライン: 「1つの投稿に1つのアイデア。いいと思ったら 👍 で票を入れてください。」
- 並び順を「リアクションの多い順」にすると、人気の要望が上に来る。

## 3. ロールと設定

| ロール | 持つ人 | できること |
|---|---|---|
| `運営` | オーナー(+手伝ってくれる人) | すべてのチャンネルに書ける、メッセージの管理、`🔒 運営` が見える |
| `テスター` | 参加した友達全員 | 普通のチャンネルに書ける、通話 |
| (`@everyone`) | 入ったばかりの人 | `#ようこそ` だけ見える。ルールに 👍 したら `テスター` を付ける(手動でよい) |

- **入ってすぐ全部見えるのが楽なら**、`@everyone` に普通のチャンネルを見せて、`テスター` ロールは省いてもよい。人数が少ないうちはそれで十分。
- **招待リンク**: 期限「1日」・回数「1回」で、渡す相手ごとに作る。使い回さない。
- **認証レベル**: 「低」(メール認証済み)以上。
- **不適切な画像のフィルター**: 「全員のメッセージをスキャン」。
- **通報の Webhook**: Peta の Worker に設定した `REPORT_WEBHOOK` の行き先は、`#通報通知`(運営だけが見えるチャンネル)にする。通知には件数と ID しか入らないが、通報があったこと自体を友達に見せないため。今の Webhook がほかのチャンネルを指していたら、`#通報通知` で新しく作り直して `npx wrangler@4.149.0 secret put REPORT_WEBHOOK --env prod` で入れ直す。
- サーバーのアイコンは Peta のアイコン(`src-tauri/icons/128x128@2x.png`)が使える。

## 4. 立ち上げの手順

1. Discord で「サーバーを作成」→「オリジナルの作成」→「自分と友達のため」。名前は `Peta` など。
2. §3 のロールを作る(`運営` を自分に付ける)。
3. §1 のカテゴリとチャンネルを上から作り、権限を設定する。フォーラムが作れなければコミュニティを有効にする。
4. フォーラム3つに §2 のタグとガイドラインを入れる。
5. §5 の文面を各チャンネルに貼る(`【】` を埋める)。`#ダウンロード` のリンクは Peta のダウンロードページ(docs/download-page-howto.md)。入れる友達のメールアドレスを、先に管理ページの Friends(= Cloudflare Access の `Peta friends`)へ足しておく。
6. `#通報通知` の Webhook を作り、必要なら Peta 側の secret を入れ直す(§3)。
7. 自分の別アカウントか、最初の友達1人で、入ってから迷わないかを試す(招待 → ようこそ → ダウンロード → はじめかた)。
8. 友達を1人ずつ招待する。DM でメールアドレスを受け取ったら、管理ページの **Friends** で Add friends(管理ページが使えなければ Zero Trust のポリシー `Peta friends` の「メール」に足して保存)し、「入れるようになったよ」と返す。Discord にいない友達には、同じ手順を LINE などで送る。

## 5. そのまま貼れる文面

### 5.1 `#ようこそ`

```
# Peta へようこそ 🎨
Peta は、写真から切り抜いたステッカーを Mac のデスクトップに貼って楽しむアプリです。このサーバーは、Peta を一緒に試してくれる友達だけの場所です。

## 最初にやること
1. ⬇️ #ダウンロード からアプリを入れる(先に運営へ DM でメールアドレスを送ってね)
2. 🚀 #はじめかた を見ながら、名前を決めて友達とつながる
3. 🧷 #フレンドコード で友達コードを交換する

## 困ったとき・気づいたとき
・🙋 まず #よくある質問 → 見つからなければ #ヘルプ に投稿
・🐞 おかしな動き → #バグ報告
・💡 こうだったらいいな → #要望・アイデア

## ルール
1. ここは招待した友達だけの場所です。招待リンク、ダウンロードページ、アプリのファイル、あなたの招待コードを外に渡さないでください。
2. 鍵のバックアップ(.petakey)、移行ファイル(.petamove)、そのパスフレーズは、誰にも・どこにも貼らないでください。これがあると、あなたの Peta になりすませます。運営も聞きません。
3. ステッカーにする写真は、自分で撮ったものか、使ってよいものにしてください。他の人が写っている写真は、その人がいいと言ったものだけ。
4. 嫌がらせ・晒し・他人の作品の無断の再配布はしないでください。
5. Peta はまだベータ版です。データが消える可能性はゼロではないので、大事なものは自分でも残しておいてください。

ルールを読んだら、このメッセージに 👍 を押してください。
```

### 5.3 `#ダウンロード`

```
# ⬇️ ダウンロード

## はじめての人
1. **運営(@【運営の表示名】)に DM で、メールアドレスを送ってください**
   → 運営が登録したら「入れるようになったよ」と返事します(チャンネルには書かないでね)
2. 返事が来たら、このページを開いてください
   👉 https://peta-download-prod.peta-api.workers.dev
3. 送ったメールアドレスを入れる → メールに届く **6桁のコード** を入れる
   (パスワードはありません。1か月はログインしたままです)
4. ページの「Download for Mac」から .dmg を落として開き、Peta を「Applications」へドラッグ
5. Peta を開くと **招待コード** を聞かれるので、ページに出ているコードを貼る

🔓 **最初に開くとき**(Apple の確認をまだ通していないベータなので、1回だけ)
・「開発元を検証できません」と出たら **完了** を押す
・**システム設定 → プライバシーとセキュリティ** を開き、下のほうの「Peta は…」の横の **このまま開く** → Mac のパスワード
・DMGで入れ直した場合は、この手順をもう一度求められることがあります。通常の更新は下のアプリ内更新を使ってください。

⚠️ ページのリンクも招待コードも、外に渡さないでください。コードは Mac 1台だけで使えます。

## 新しい版にするとき
1. アプリに「Peta … is ready.」が出たら **Restart to update** を押します。後でよければLater。
2. 手動で確認したいときはSettings → About Peta → Check for updates。
→ ステッカー・友達・Scraps・招待はそのままです。更新がうまくいかないときだけ、ダウンロードページのDMGで入れ直してください。
→ 未公証アプリの確認は配布時の実機結果に従います。DMGで入れ直すと「このまま開く」が再び必要になることがあります。

## 新しい Mac に変えたとき
ページの「Moving to a new Mac? Get a new code」で新しいコードを出して、新しい Mac で入れてください。古い Mac は友達とつながらなくなります。

## データの場所(念のため)
~/Library/Application Support/app.peta.desktop/
ここを消すと、ステッカーも鍵も消えます。消さないでください。
```

### 5.4 `#はじめかた`

```
# 🚀 はじめかた

## 1. 名前を決める
Settings で名前を決めてください。友達に表示される名前です。名前を決めないと、友達コードや Gift は使えません。

## 2. 友達とつながる
1. Settings → Friends → **Copy code** で自分の友達コードをコピー
2. #フレンドコード に貼る
3. 相手のコードをコピーして、Settings → Friends → **Add a friend…** に貼って送る
4. 相手が **Approve** すると友達になります
💡 申請や Gift は数分〜15分ごとに自動で確認します。すぐ見たいときは Settings → Friends の **Check now**。

## 3. ステッカーを作って貼る
Create で写真を選んで切り抜き → 名前を付けて「Make this Peta」→ デスクトップに貼れます。
作るたびに素材を1枚使います。新しい写真で作った日は Scraps がもらえます。

## 4. Gift(ステッカーを1枚あげる)
Studio → Gift → ステッカーを選ぶ → 宛先に友達を選ぶ → 封をして送る
・あげたステッカーは、あなたの手元からなくなります(世界に1枚のステッカーなので)
・届いた Gift は封筒で届きます

## 5. パックと Market
・Studio → Pack で、自分のステッカーを3枚以上入れたパックを作れます(版=番号つきの枚数を決めます)
・Packs → My shelf → パック → **Show to friends in Market** で、友達の Market に並びます
・友達のパックは Market の下の「From 〇〇」から、1回 6 Scraps で1枚ずつ引けます
・売れると、あなたに Scraps が入ります(1回につき約7割)
・#パックの宣伝 で告知すると引いてもらいやすいです

## 6. Scraps(スクラップ)
アプリの中だけのポイントです。お金では買えず、換金もできません。
最初に 20、新しい写真でステッカーを作ると +2(1日1回)、7日続けると +5。

## 7. 大事: 鍵のバックアップ
Settings → **Back up your key** で、あなたの Peta の鍵をパスフレーズ付きで保存できます。
鍵をなくすと、持っているステッカーを二度と渡せなくなります。保存したファイルとパスフレーズは、自分だけで持っていてください(ここには貼らないで)。
Mac を買い替えるときは Settings → **Move to a new Mac**。
```

### 5.5 `#フレンドコード` の固定メッセージ

```
🧷 友達コードの交換所
自分のコードを貼って、ほしい人は Settings → Friends → Add a friend… に貼って申請してください。
・コードは Settings → Friends → Copy code で取れます
・申請が来たら Approve で友達に
・コードには名前と公開鍵だけが入っています(このサーバーの中なら貼っても大丈夫です)
・知らない人に渡したくない場合は、DM で交換してください
```

### 5.6 `#よくある質問`

```
# 🙋 よくある質問

**Q. 開こうとすると「開発元を確認できません」「壊れているため開けません」と出る**
A. 右クリック →「開く」→「開く」で開けます。だめなら システム設定 → プライバシーとセキュリティ の「このまま開く」。それでもだめなら #ヘルプ へ。

**Q. 友達コードを送ったのに、相手に申請が届かない**
A. 相手側で Settings → Friends → Check now を押してもらってください。自動の確認は15分ごとです。相手が「When I open Peta」にしていると、アプリを開いたときだけ確認します。

**Q. Gift の宛先に友達が出てこない**
A. 相手が Approve するまでは友達になっていません。Settings → Friends の「Friends」に名前があるか見てください。

**Q. Gift を送ったのに届かない**
A. 届くのは、相手の Peta が次に確認したときです(最大15分)。相手に Check now を押してもらうと早いです。7日受け取られないと期限切れになり、その後の確認で、ステッカーはあなたの Collection に戻ります(「…came back to your Collection.」と知らせが出ます)。

**Q. 友達のパックが Market に出てこない**
A. 友達になっている(お互いに Approve 済み)ことが条件です。出品した人が一時停止(Take down)していると「Back soon」、全部引かれると「Sold out」になります。Market を開き直すと最新になります。

**Q. Pull を押したら Scraps が減ったのに、何も出てこなかった / 通信が切れた**
A. 払った記録は残っていて、つながったときに同じ枠で自動でやり直します。二重に払うことはありません。売り切れなどで引けなかったときは Scraps が戻ります。しばらくしても戻らなければ #ヘルプ へ。

**Q. 自分のパックを自分で引けない**
A. 仕様です。自分のパックは自分では開けません。

**Q. 「That's enough pulls for today」と出る**
A. 1人1日 20 回までです。翌日にまた引けます。

**Q. 「Connect to the internet to …」と出る**
A. 友達・Gift・Market はインターネットが必要です。ステッカーを作る・貼るのはオフラインでもできます。

**Q. 新しい Mac に移りたい**
A. 古い Mac で Settings → Move to a new Mac → 書き出し。新しい Mac に Peta を入れて、**最初に起動したとき**にそのファイルを読み込みます(一度使い始めた Peta には読み込めません)。移した後は、古い Mac で Peta を使わないでください。

**Q. 友達をやめたい / 申請を断りたい**
A. Settings → Friends で Remove(友達をやめる)・Decline(断る)・Block(申請も Gift も受け取らない)。もらったステッカーは手元に残ります。

**Q. いやな Gift やパックが届いた**
A. Gift は Gifts の画面の Report… から、運営に知らせられます(中身を運営が見ることに同意した場合だけ送られます)。Block もできます。

**Q. Peta をやめたい**
A. Settings → Friends の一番下から、サーバー上の受信箱を消せます(ステッカーは Mac に残ります)。その後でアプリを消してください。データも消すなら ~/Library/Application Support/app.peta.desktop/ を消します(元に戻せません)。
```

### 5.7 `#ヘルプ`・`#バグ報告` に最初に置く投稿

## 6. 運営の流れ

### 新しい版を出すとき
1. 直したバグのスレッドに `修正済み・次の版` を付けておく
2. コミット済みの状態で版を上げ、暗号化ディスク上の更新鍵を指定して`bash scripts/release-mac.sh beta`（未公証なら`--unsigned`）。公開鍵入りアプリ・DMG・更新アーカイブ・署名を作る。docs/updater-howto.mdを参照。
3. まずdevへ公開し、アプリ内更新と再起動・データ保持を確認する。DMGも初回と復旧用に確認する。
4. 確認後、`bash scripts/publish-release.sh src-tauri/target/release/distribution/Peta-<版>.dmg prod --notes "What changed"`（未公証なら`--unsigned`も付ける。ファイルが揃ってから案内が切り替わる）
5. `#お知らせ`(§5.2)と `#変更履歴` に書く
6. バグのスレッドを `リリース済み` にして、報告してくれた人にひとこと

### バグ報告を受けたら
1. `新規` → 読んだら `確認中`
2. 手元(2つのユーザー)で再現できたら `再現できた`。できなければ、もう少し聞いて `再現できず`
3. 直す(Claude / Codex に、スレッドの内容をそのまま渡す)
4. 次の版に入れたら `修正済み・次の版` → 公開したら `リリース済み`

### 通報が来たら
1. `#通報通知` に件数と ID が来る(中身は来ない)
2. `docs/server-howto.md` の「通報を見る・対応する」に沿って中身を確認する
3. 必要なら、その人と話す・鍵を止める
4. 対応を終えたら `resolved_at` を記録する(30日後に自動で消える)

### サーバーが止まったら
1. `curl -s https://peta-api-prod.peta-api.workers.dev/v1/health` で生きているか見る
2. Cloudflare のダッシュボードで Workers・D1 のエラーと使用量を見る(D1 の1日の上限に届くと、日本時間の朝9時まで止まる)
3. `#お知らせ` に障害の文面(§5.2)を出す
