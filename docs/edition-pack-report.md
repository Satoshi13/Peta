# Pack の版と景品 実装報告

2026-10-12 追記：My shelf を完成済みパックの保管・再書き出し場所に変更しました。同じ署名済みファイルを保持し、再 press・景品の追加消費・補充は行いません。保存後の表紙・装飾と Studio の表示修正は [Studio 修正報告](studio-fixes-oct12-report.md) に記載しています。Market の出品・取り下げは未実装です。

2026-10-11。V12 の本物/複製・Gift v3 を前提に DB V13 と PETAPACK v2 を実装しました。見た目の仕上げは含めず、既存の画面・演出を使っています。

## 作ったもの

- 新パックのデザインは copies、景品は material/tag の count。各版の番号・総数・作者証明・release を含めて署名します。版の証明を Gift v3 に移しても検証できます。元写真は入りません。
- copies は1〜30、景品合計10個、スロット合計200個。Rust の定数を画面へ返して上限表示に使います。多数の署名を収める v2 ヘッダは最大1MiB、全ファイルは24MiBのままです。
- V13 は signed_pack_items の番号/総数/景品種別に加え、原本の pressed、版の番号のサーバー確認情報、固定スロット番号と署名履歴を追加します。V12 の本物と旧 weighted 行は保持します。
- press は原本を残して一度だけ版を発行し、受け取った本物は1枚だけパックへ移します。複製は Rust でも拒否。原本の飾り用複製とタグは残りますが、移動する本物の複製・配置・タグは整理します。
- 素材と未装着タグを実在庫から移します。開発者版でも素材の移動は実数です。不足・保存失敗・Referee 拒否・SQL 失敗で SQLite の変更を戻します。書き出しには Gift と共通の復旧ジャーナルを使います。
- 同タイトルの再発行・既存 v2 の改訂による増刷・補充を拒否します。My shelf の自作パックを鍵で識別し開封を拒否します。画面には Your own pack: friends open it と表示し、Open は出しません。
- v2 は残りスロットから一様に引き、売り切れます。無料開封も有限スロットを消費します。旧 v1 の重み・公式パック・Welcome・無料コピーは従来の流れを維持します。
- 開封は版または景品の付与・スロット消費・来歴・必要な印刷待ちを同じトランザクションで確定。Referee に公開 pack_id とヘッダから決まる slot_no を渡します。端末ごとの SQLite 行番号は使いません。
- Studio は Gather / Dress / Seal を維持し、Editions の枚数入力・割合・総スロット数・Prizes を追加。受け取った本物は1枚に固定、pressed は選択不能、カバーは選んだ自作デザインだけ。単発/複数開封は既存演出を流用し、景品は既存の素材カード/タグを表示します。

## 検証

Rust workspace：core167件、アプリ5件、原本管理5件、CLI統合1件が成功。JS135件と check:mac / check:mac:developer が成功。通常版の release ビルドも成功（Peta.app 53.10 MiB）。テストでは以下を確認しました。

- V12→V13 と旧形式のデータ保持、v1 の重み抽選/TOFU/公式配布/無料開封の回帰。
- copies・prizes・版の番号の改ざん、0/31枚、201スロット、景品11個、未知素材の拒否。200スロットの最大パックの署名と読込。
- 一度だけの発行と原本/複製の保持、受け取った本物1枚の移動と複製整理、在庫不足と装着済みタグの拒否。
- 保存失敗・SQL途中失敗・Referee の claim_slot 拒否で、景品/本物/発行印/残数を巻き戻す。日次記録と印刷待ちも残らない。COMMIT 失敗時には既存の書き出しファイルを復元する。
- 別 Library での開封、画像3デザインに対して保存画像も3組だけ、版の ID/番号の非重複、全スロットで売り切れ、景品の在庫への追加、自作パックの拒否。
- 固定乱数の再現性と一様なスロットの選択、無料開封が有限の残数を減らすこと、版を Gift で転送しても番号/総数を維持すること。
- Studio の下書き復元でも、景品の重複・現在の在庫・景品数と全スロットの上限を確認する。

## 守れないこと・実機確認

審判がない間、同じパックのファイルを複数人が別々に開くと、同じ番号の版が複数現れます。NoReferee は全てを許可します。作者の署名が確認できても、全端末共通で番号が一度だけ消費された保証にはなりません。版の裏に Edition numbers are not checked by a server yet と表示します。

価格・Scraps の支払い・売り手の取り分・封をしたパックの二次流通は実装していません。CREATOR_PACK_PRICE は後工程のための未使用定数だけです。

実際の2インスタンス間のファイル受け渡し、Studio の操作感、景品が混ざる開封の表示は、オーナーが `port-spec/macos-checklist.md` で確認してください。テスト用の別 Library による経路は確認済みです。
