# Boards(台紙)要件 — 画面の飾りを保存して切り替える

決定日: 2026-10-12(オーナー)。**2026-10-13: DB・core・Auto・購入・メニューバー・UI 接続を実装済み（通常版にも公開）。実機確認はオーナー待ち**。作業順の①「ツール」の1つ。旧称「机の飾り方(Desk layouts)」は廃止(机としては見ていないため)。画面の依頼書は [`codex-boards-ui-prompt.md`](codex-boards-ui-prompt.md)。

## ひとことで

**画面(モニター)ごとの飾り**は、Peta が自動で覚えている(無料)。気に入った飾りは**台紙(Board)を1枚使って**名前をつけて保存でき、いつでも好きな画面に呼び出せる。呼び出すと、その画面の飾りが Board の内容で上書きされる。さらに**時間帯や場所**で、どの画面にどの Board を出すかを決めておける。

## 2つの保存

| | 画面の記憶(Screen) | Board(台紙) |
|---|---|---|
| 何か | 各モニターの「いまの飾り」 | 名前のついた飾りの保存 |
| いつ保存 | 自動(貼る・動かす・剥がすたび) | 「Save as board」を押したとき |
| 費用 | 無料 | **台紙を1枚使う**(在庫から減る。消すと戻る) |
| 数 | つないだことのあるモニターごとに1つ | 台紙の在庫ぶん |
| 使い道 | モニターを外すとしまい、つなぎ直すと戻す | 好きな画面に呼び出す(その画面の記憶を上書き) |

## 決めたこと(オーナー、2026-10-12)

1. **名前は Boards(台紙)**。Market の Tools の品は **Board ×1**(白紙の台紙1枚)。
2. **画面の記憶は無料・自動**。モニターを外すと、その画面のステッカーは描画せずしまい（配置は保持）、つなぎ直すと元どおりに戻る。
3. **Board の保存は台紙を1枚使う**。ステッカーを貼った画面から「Save as board」で保存する。
4. **Board を呼び出すと、選んだ画面にその Board が貼られる**(その画面のステッカーを全部剥がして Board どおりに貼る)。画面の記憶も Board の内容で上書きされる。直前の飾りは Undo で1回戻せる。
5. **時間帯・場所で Board を指定できる**(Auto)。例: 平日 9:00〜18:00 は外部モニターに「Work day」、自宅の Wi‑Fi では「Autumn」。
6. 最初に**白紙の台紙を 2 枚**持っている。3枚目から Tools で Board ×1 を Scraps と交換(値段は②の経済で決める)。
7. **メニューバーから呼び出せる**(`Boards ▸`)。
8. 保存するのはステッカーへの参照だけ(コピーしない)。呼び出しは「今日の1枚」に数えず、Scraps も動かない。画面のスクリーンショットは使わない(Board の絵はステッカーの画像から描き直す)。

## Claude が決めた点(違えばオーナーが直す)

- ~~Board を消しても台紙は戻らない~~ → **2026-10-12 変更(オーナー): 消すと台紙は白紙で戻る**(リンクタグと同じ「何度も使える道具」)。台紙の数は実質「保存できる枠の数」。**既存の Board を今の飾りで上書きする(Update)のは無料**。
- Board の位置は画面に対する割合で覚えるので、大きさの違う画面にも呼び出せる。
- **1枚のステッカーは1か所にしか貼れない**。呼び出した Board のステッカーが別の画面に貼ってあれば、動かさずに飛ばす(Board の絵では点線の影と「On another screen」)。手元にないもの(送った・パックに入れた)も飛ばす(「No longer yours」)。
- **Auto のきまり**: 条件が「始まったとき」(9:00 になった、その Wi‑Fi につないだ)に1回だけ貼る。そのあと手で変えたら、次の条件が始まるまでそのまま。2つの条件が同時に始まったら、一覧で上にあるものが勝つ(並べ替えできる)。
- **場所 = Wi‑Fi のネットワーク名**。macOS 14 以降は Wi‑Fi の名前を読むのに位置情報の許可が要るので、**最初に場所のきまりを作るときだけ**許可を求める。位置や Wi‑Fi の名前は端末の外に出さない。
- Auto は最初は無料。あとで Tools の品にするかは②で決める。

## 見た目(オーナー、2026-10-12)

- 台紙の素材は **布張りのボード**(`src/art/ui/board-linen.webp`。生成り色のリネンに同色のステッチ、角丸。比率 960:589 で画面に近い横長)。ピンやバッジのコレクターが使う展示ボードのイメージ。
- ボードの上にはステッカーだけを並べ、名前はボードの下に手書きで書く。使用中は右上に緑のチェック。
- 名前に「Mat」は使わない(素材の Matte、Create のカッティングマットと紛らわしい)。品名は **Board ×1** のまま。
- Market の Tools はリンクタグと Board の2枚の紙のカードを並べる案(オーナーのラフ)。Board のカードの絵も布のボードにする。

- Boards のページには購入の欄を置かない(Market の Tools と重複するため)。右上に白紙の残り枚数、0枚なら Market への案内。台紙は押すとその画面に貼られ(カーソルを乗せると `Put on <画面>`)、下は手書きの名前と「•••」、その下に小さな補足1行(使用中・Auto・ほかの画面にある枚数)。
