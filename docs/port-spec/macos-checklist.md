既存の開発環境で `npm ci`、`npm run build` を行い、生成された `src-tauri/target/debug/bundle/macos/Peta.app` を開く。開発版だけでなく、**.app を直接起動した状態**でも下の動作を確認する。ユーザーの通常のライブラリを変更しないよう、専用の macOS テストアカウントを使う。Linux の XDG_DATA_HOME 指定を macOS のデータ分離として扱わない。

テスト用画像、空のデスクトップ、Finderのアイコン、他アプリの通常窓、2台以上の画面（可能なら Retina と非 Retina）を用意する。まず1画面で Studio / Desk を確認し、その後2画面にする。有限素材を消費する必要がない操作は Matte で行う。

各項目は **OK / NG / 未確認**、実際の結果と画像・動画を記録する。NGをチェック済みの合格にしない。
