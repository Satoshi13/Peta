# Peta のデザイン原則

> 静かなシステムの画面に、手触りのある小物がそっと置かれている。人のいない、少し懐かしい場所。

画面・素材・演出を足すときや直すときは、まずこの文書に照らします。個々の決定は [decisions.md](decisions.md)、数値の正解は [port-spec/tokens.md](port-spec/tokens.md) と `src/app/css/base.css` の `:root` にあります。迷ったら、この文書の「やらないこと」を優先します。

## 1. 二つの層のギャップ（いちばんの軸）

| 層 | 何でできているか | 例 |
|---|---|---|
| 土台 | 整った Mac 純正のような画面。平らで静か、システムの文字 | 窓、サイドバー、設定の行、一覧、ダイアログ、主ボタン |
| 小物 | 実物の画風で描いた机の上の物 | 紙の札、マスキングテープ、クリップ、封筒、クラフト紙、水彩のステッカー |

- 「デジタルの画面の上に、誰かが机の小物をそっと置いていった」という食い違いが Peta らしさです。
- **土台を飾らない。** 土台に紙の質感・手書き体・傾き・テープを足しません。平らな面は `--w-*` トークンの単色です。
- **小物をフラットにしない。** 小物を CSS の単色の四角や絵文字で代用しません。描いた素材（`src/art/`）を使います。
- 一つの部品は、どちらの層に属するかが一目で分かること。両方の性格を半分ずつ持った部品は作りません。

## 2. liminal な静けさ

- 余白を多く取り、人の気配を減らします。物だけがそこに置いてある状態が基本です。
- 夕方の文房具屋、誰もいない教室の机、片付いた作業台のような、時間が止まった少し懐かしい空気を目指します。
- 何かを促したり急かしたりしません。
  - 待機中に動き続けるアニメーション、点滅、脈動を置きません（演出は「表示した最初の1回」だけ）。
  - バッジの数字は、本当に未読のものがあるときだけ。赤い丸で煽りません。
  - 「今すぐ」「残りわずか」「お見逃しなく」のような文言を使いません。
  - 通知・音・触覚は、ユーザーの操作が成功した瞬間に1回だけ。
- Reduce motion（アプリ設定・OS設定どちらでも）では、移動・拡大・回転を省いて完成状態を即時に表示します。

## 3. 質感は本物っぽく、でも写真ではない

- 紙の繊維、クラフトのざらつき、箔やホログラムの淡い光、テープのしわ。
- 描いた絵（水彩・手描き）であって、写真や3Dではありません。
- ツヤ（スペキュラ）、強い光の反射、レンズフレア、ブルームを使いません。箔・ホロの光は淡く、面の上をゆっくり移るだけにします。
- `perspective` を使った傾きは小さく（数度まで）し、物が「立ち上がる」ような3D表現にしません。

## 4. 光と影

- **光は左上から。影は右下へ、薄く短く。** 「紙が少し浮いている」くらいの距離感です。
- 影はできるだけ `--sh1`〜`--sh3` のトークンを使います。個別に `box-shadow` / `drop-shadow` を書くときも、同じ規則に従います:
  - x と y のオフセットはどちらも 0 以上（右下）。y は x 以上。
  - 最も強い `--sh3` でも、オフセットは 6px 以下、ぼかしは 24px 以下、不透明度は 0.22 以下。
  - 影の色は暖かい焦げ茶（`rgba(60,45,20,…)`）。黒い影や色つきの光彩は使いません（Night では黒系を許可）。
- 持ち上げる（ホバー・ドラッグ）ときも、影は少し長く・薄くなるだけで、方向は変えません。

## 5. 色

| 役割 | 色 |
|---|---|
| 基本 | クリーム `--cream`、紙 `--paper`、柔らかい白 `--soft`、クラフト `--kraft`、黒鉛のような黒 `--ink` |
| 補助の文字 | 暖かい濃色 `--muted`（本文とのコントラスト 4.5:1 以上） |
| 差し色 | ホログラムの淡いパステル `--holo`（ピンク・ラベンダー・空色・ミント・レモン）、銀・金の箔 |
| 注意 | `--red` は取り消せない操作の確認と、エラーの文言だけ |

- 彩度は抑えめ。強い原色（純色の赤・青・緑・黄、蛍光色）は使いません。
- 新しい色を足すときは、既存トークンから作れないか先に確かめ、足すなら `base.css` の `:root` に名前を付けて置きます（Day と Night の両方）。

## 6. 文字

| 役割 | 書体 | 使いどころ |
|---|---|---|
| 画面の言葉 | システム書体 `--sys` | 見出し、説明、ボタン、在庫。簡潔に |
| 札・小見出し | タイプライター風の等幅 `--tag-type` / `--tag-track`（Special Elite 13px、字間 .14em、大文字。`.eyebrow` が使う） | 字間の広い大文字のラベル（「FRIENDS OF PETA」「MAKE YOURSELF AT HOME.」）、日付・時計・Scraps の印字。13px 以上 |
| 物に書かれた字 | 手書き体 `--hand`（Klee One など） | 裏紙、ギフトのメモ、値札など「物」の上だけ |

- 補足は 12px 以上、Overline は 11px。本文のコントラストは 4.5:1 以上。
- 手書き体を土台（設定・一覧・ダイアログ）に使いません。等幅を長い文章に使いません。
- 文言は短く、平叙文で。感嘆符・絵文字・煽り文句を使いません。

## 7. 気分

- 静かで、大人のかわいさ。
- かわいいけれど甘すぎず、懐かしいけれど古びていない。

## 8. やらないこと

- **ゲームの画面にしない。** レベル、経験値、ゲージ、連続日数の大きな表示、派手な獲得演出、コンボ、ランキング。
- **ガチャを主役にしない。** 開封は静かな儀式で、確率や当たりを煽りません。レアの光は淡く短く。
- **フォトリアル・3D・ギラギラした光。**

進捗の表示が必要な場合（無料開封までの数など）は、ゲージではなく「小さな印が並ぶ」「紙に書かれた数」のような、物の言葉で表します。

## レビューのチェックリスト

新しい画面・部品・演出を入れる前に確かめます。

- [ ] 土台と小物のどちらの層か一目で分かる。土台に紙・手書き・傾きが混ざっていない
- [ ] 待機中に動き続けるもの・点滅・脈動がない。演出は最初の1回だけ
- [ ] Reduce motion で完成状態が即時に出る
- [ ] 影は `--sh*` トークンだけ。右下・薄く短い
- [ ] ツヤ・強い反射・3D の立ち上がりがない
- [ ] 色はトークンから。強い原色がない。`--red` はエラーと取り消せない確認だけ
- [ ] 文字の役割（システム／等幅の札／物の手書き）が守られ、12px 以上
- [ ] 文言に煽り・感嘆符・絵文字がない
- [ ] レベル・ゲージ・ガチャを主役にする表現がない
