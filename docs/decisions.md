### Pack のデザイン(仕様 §39)

仕様書の §39 には 2 つの案が混在している。**どちらも残し、実物を作って見比べてから決める。**

- **案A: 紙箱 / スリーブ / カードパック型**(仕様書の推奨)
  薄い紙箱やカードケース感。平面で、UIとして実現しやすい。
- **案B: 銀色の密封袋型**(オーナーの好み)
  小さな銀色の密封パウチ。ホログラム素材との相性が良く、開封の「儀式感」が出る。
  ただし柔らかい質感の表現はフォトリアルになりやすく、NG 2(過度なフォトリアル禁止)に注意。

## 用語メモ: 「MVP」とは

Minimum Viable Product。**「最初に世に出して検証する、最小の版」**のこと。
Gift / Pack を「作らない」のではなく、**「最初のAlphaには入れず、あとで順に入れる」**という順番の話。

Gift はアカウント・サーバー・送受信が必要で、実装が一気に重くなる。一方、Peta の核
(「毎日1枚作って貼り、翌日もそこにある」が楽しいか)は Gift なしで検証できる。
そこで次の順にしている(仕様 §71-79):

1. Phase 0-5: デスクトップ / 1日1枚 / 作る / コレクション ← **ここまでが MVP(最初のAlpha)**
2. **Phase 6: Pack**(ローカルのみ。サーバー不要なので早めに入れられる)
3. **Phase 7: Account + Gift**
4. Phase 8: Marketplace
