# このMacのMarketへの出品・取り下げ（2026-10-12）

My shelf の完成済み自作パックを、同じMacの Market に表示・非表示にする操作を追加しました。季節が変わったら取り下げ、同じ完成品を再出品できます。

## 操作

- Packs → My shelf → パックの詳細 → **List in Market**。
- Market の **On this Mac** に、表紙・包装・配置・飾りを含む同じ完成済みパックが表示されます。
- My shelf または Market の詳細から **Take down from Market**。My shelf には残ります。
- 再出品も同じボタンで行えます。**Save file…** から同じ署名済みパックを再書き出しできます。

出品はこのMac内の表示切り替えです。共有Market、他のMacへの自動公開、購入・売上・値段の仕組みは接続していません。自作パックを自分で開ける操作も追加していません。

## 保存と整合性

DB V14 の `pack_market_listings` に公開状態を保存します。既存パックは非公開で移行し、再起動後も状態を保持します。packId ごとに1行なので、繰り返しの出品で表示や枚数が増えません。パック削除時は出品情報も削除されます。

出品時は同じ transaction 内で、棚への登録済みV2パックであること、実際の端末鍵と作者鍵、ヘッダ・内部ID・外部ID・バージョンの一致を確認します。表示用の「自作」印だけでは許可しません。他人の作品、旧形式パック、サンプル、棚に置いていないファイルだけのパックは出品できません。

取り下げは署名鍵やメタデータが読めなくても解除できます。表示状態の変更は、press・開封・補充・アーカイブ復元・在庫の消費を行いません。版番号・残数・画像・景品・所有履歴・署名済みファイルはそのままです。

UI は native の成功を受け取った時点で出品状態を確定し、その後の状態取得に失敗しても成功を失いません。保存中の連打を防ぎ、詳細を閉じた後に保存が完了した場合も背景の棚を更新します。
