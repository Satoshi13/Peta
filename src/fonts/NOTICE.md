These files are bundled for offline Aa Std, preserving the prototype's font stacks.

- Klee One Regular / SemiBold: Google Fonts `ofl/kleeone`, SIL Open Font License (KleeOne-OFL.txt).
- Kalam Light / Regular (Latin subset, WOFF2): Google Fonts `ofl/kalam`, SIL Open Font License (Kalam-OFL.txt). Used for the handwritten counts on the Packs shelf.
- Patrick Hand Regular (Latin subset, WOFF2): Google Fonts `ofl/patrickhand`, SIL Open Font License (PatrickHand-OFL.txt). Used for the name written on the Create name tag.
- Kiwi Maru Regular (hiragana, katakana, symbols and the 2,965 level-1 kanji, WOFF2): Google Fonts `ofl/kiwimaru`, SIL Open Font License (KiwiMaru-OFL.txt). The Japanese half of the name on the Create name tag, set with Patrick Hand.
- Special Elite Regular: Google Fonts `apache/specialelite`, Apache 2.0 (SpecialElite-LICENSE.txt).
- Courier Prime Regular: Quote-Unquote Apps `CourierPrime/fonts/ttf/CourierPrime-Regular.ttf`, SIL Open Font License (CourierPrime-OFL.txt). Used for the centered Collection name label. Source: https://github.com/quoteunquoteapps/CourierPrime
