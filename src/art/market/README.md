# Market の小物素材（2026-10-08）

承認された Market の見本から、各パーツを単体で描き直した納品素材です。
吊りクリップは正面に描き直し、リング・接続部・挟み板の中心を揃えました。
各 PNG は透明背景・左上からの光・右下への短く薄い影を含みます。
生成原本を拡大して透過の縁と影を整えた書き出しで、長辺はすべて 2400px 以上です。

| ファイル | パーツ |
|---|---|
| `cork-board.png` | 空のコルクボード。キャンバス 3000×1000（3:1） |
| `paper-clip-silver.png` | 縦向きの銀の紙クリップ |
| `rail-bar.png` | 左右に繰り返せる、端のない棒 |
| `rail-clip.png` | 正面向きのリングと挟み板。袋・棒は含まない |
| `memo-card-blank.png` | 文字・穴・金具のないクリーム色の紙 |
| `rail-end-left.png` | 棒への接続部が右向きの左端 |
| `rail-end-right.png` | 棒への接続部が左向きの右端。独立して描いた左上光 |

サイズ・透明領域・元の生成サイズは [manifest.json](manifest.json) に記録しています。
棒の左右端の RGBA と隣接する列は完全に一致します。横方向に繰り返し、縦横比を保ってください。
端の金具は接続部の太さで縮尺を合わせ、リングの中心を棒に合わせます。
ボード・紙の伸縮には 9 スライスを使い、四隅を保ってください。
素材に薄い影を含むので、追加の影を重ねる場合は濃さを調整してください。

今回のユーザー指定に従った形状・比率で納品しています。
`docs/codex-market-props-prompt.md` の寸法表に合わせた再書き出し、⑦コルク地、任意の紙、接続座標は未作成です。


見本と素材一覧は [納品レポート](../../../docs/ui-proposals/market-assets-2026-10-08/README.md) を参照してください。

## アプリで使っている版について

このフォルダの PNG は、納品された元サイズ（上の表と `manifest.json` の寸法）を、**アプリの表示サイズの4倍**に縮小・調整した版です。元サイズの PNG は git の履歴（コミット `f5c3564`）にあります。

- コルクボード 1800×606（余白を切り詰め、256色）、メモ 1200×549（同）、紙クリップ 64×256、レール棒 767×52、レール端 190×135 前後、吊りクリップ 85×184
- 位置合わせの数値は [anchors.json](anchors.json)（棒の中心、リングの中心など）。CSS は `src/app/css/native.css` の「Market:」の節
- 棒の太さは表示10px、端の筒の太さもそれに合わせて縮小（元の約550px → 40px）
- 再書き出しが必要なときは、元サイズの納品から同じ手順で作り直す
