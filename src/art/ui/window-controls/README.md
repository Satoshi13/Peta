# Peta — 紙のピル型ウィンドウ操作素材

白い台紙と赤・黄・緑の丸を独立した背景透過PNGにしています。紙の質感・縁・薄い影を画像に含みます。CSSの追加の影は不要です。

| ファイル | PNGサイズ | 推奨表示サイズ |
|---|---|---|
| pill-backing.png | 432 × 144 | 108 × 36 CSS px |
| button-red.png | 96 × 96 | 24 × 24 CSS px |
| button-yellow.png | 96 × 96 | 24 × 24 CSS px |
| button-green.png | 96 × 96 | 24 × 24 CSS px |

すべて4倍解像度。サイズは透明余白と影を含みます。丸の見える紙部分は約22pxです。

108 × 36pxの親要素に台紙を全面配置し、ボタンをleft: 10 / 42 / 74px、top: 6pxで重ねます。3つの中心は(22,18)、(54,18)、(86,18)です。

example.html に表示例とHTML/CSSを同梱しています。閉じる・最小化・最大化の実処理はアプリ側で接続してください。ドラッグ可能なタイトルバーに置く場合、ボタンをドラッグ領域から除外してください。

assembled-preview.png は重ね合わせ確認用です。実装では独立した4ファイルを使用してください。

ブラウザ標準のfocus-visibleを残しています。画像には操作記号を入れていません。
